# 🎟️ 券来

**设好时间，每天少点几下。**

一个在 Windows 本机运行的美团自动领券小工具：登录一次，安排每日领取，成功或失败都能查记录。

[下载候选版](https://github.com/universe-1234/quanlai/actions/runs/36417621273) · [历史版本](https://github.com/universe-1234/quanlai/releases) · [验证记录](docs/validation.md)

## ✨ 能帮你做什么

- **每天自动领**：自己选时间，Windows 下关闭窗口后仍可执行。
- **随时改安排**：修改时间、关闭自动领取，或者立即领取一次。
- **结果看得见**：保留最近 100 次记录，展示上游实际返回的券信息。
- **重开不用重来**：恢复本地登录信息和设置；登录过期后再验证。

## 🚀 三步开始

1. **安装**：打开[候选版构建页面](https://github.com/universe-1234/quanlai/actions/runs/36417621273)，登录 GitHub，在页面底部下载 `windows-candidate`，解压后运行其中的 `.exe`。
2. **登录**：输入本人手机号，阅读并同意服务规则，再填写短信验证码。
3. **定时间**：选择每天的领取时间，点击「开启自动领取」。想先试试？点击「立即领取」。

适用于 **Windows 10/11 x64**，安装包已带齐运行组件，无需另装 Python。

> 当前为 **1.0.6-rc.1 候选版**，尚未正式发布、未签名。构建产物保留至 2026-12-27；历史版本不包含本轮全部改进。若 Windows 提示风险，请先核对下载来源，不要关闭系统安全保护。

## ⏰ 电脑也需要“上班”

自动领取需要 **电脑开机、联网，并已登录 Windows**。不必一直开着券来窗口。

| 你可能会问 | 实际行为 |
| --- | --- |
| 错过设定时间了？ | 当天启动应用、登录或恢复电脑后，尚未自动尝试就补领一次；不补往日 |
| 电脑睡着了？ | 不会主动唤醒电脑，恢复后按上面的规则处理 |
| 自动领取失败了？ | 当天不反复重试，检查原因后点击「手动重试」 |
| 今天手动领过了？ | 手动成功后，跳过当天的自动领取 |
| 不想继续自动领？ | 点击「关闭自动领取」，登录失效也能关闭；已开始的请求仍可能完成 |

按电脑本地时间执行。短信按钮上的倒计时是**重发等待时间**，不是验证码有效期。

## 🧰 遇到问题怎么办

| 提示 | 可以这样做 |
| --- | --- |
| 登录失效 | 重新登录，再手动重试 |
| 网络失败 / 超时 | 检查网络，并确认平台是否已发券，再重试 |
| 组件不可用 / 返回异常 | 检查安装完整性，或等待组件兼容修复 |
| 系统任务异常 | 点击「修复 / 确认任务」；关闭时清理失败，可再次点击关闭 |
| 记录损坏 | 先关闭自动领取，保留数据与 `.corrupt` 诊断副本后排查 |
| 执行中断 | 先在平台确认领取结果，再决定是否重试 |

没有面额或有效期就不编造，也不把“领到券”算成“已经省下钱”。最终使用条件以平台显示为准。

## 🔎 使用前了解一下

- **非美团官方产品**。登录和领券由公开发布的「美团红包助手 Skill」提供，请先阅读[服务规则](https://open-pepper.meituan.com/eds/rules/meituan-coupon-skill-service-rule.html)。活动、券数量和接口可用性由上游决定。
- **数据留在本机**。默认目录为 `%APPDATA%\券来`，无遥测、云端同步或账号托管；登录和领券仍需要联网。凭证由第三方组件管理，请勿公开整个数据目录或缓存。
- **验证范围说清楚**。自动测试、界面检查和隔离安装验证已通过；真人短信登录与真实领券尚未验证。详情见[验证记录](docs/validation.md)。

技术栈：React + Electron + Node.js + Python Skill。需要 Node.js 22+。

```sh
npm ci
npm run desktop
```

源码运行还需要本地领取组件和 Python，可通过 `QUANLAI_SKILL_ROOT`、`QUANLAI_PYTHON` 指定。Linux/macOS 源码模式需保持应用运行，本项目只提供 Windows 安装包。

**测试与 Windows 打包：**

```sh
npm test
npm run build
npx playwright install chromium
npm run test:ui
npm run dist:win
```

若固定版本组件下载失败，可先运行 `./scripts/restore-release-runtime.ps1`（需要 7-Zip 24.09+），再打包。脚本校验 SHA-256，从本仓库公开的 v1.0.5 安装包恢复原运行时，不读取个人凭证；这不代表组件已更新。
